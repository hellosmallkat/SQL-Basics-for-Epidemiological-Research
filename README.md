# Overview

This repository contains my implementation of the **National Student Data Corps (NSDC) SQL Basics for Epidemiological Research** project.

Structured Query Language (SQL) is one of the most important tools used by data scientists, analysts, and researchers for working with relational databases. In this project, I learned how to write SQL queries to analyze a real-world COVID-19 epidemiological dataset maintained by **Our World in Data**. Rather than simply learning SQL syntax, I applied database concepts to answer meaningful public health questions using real data.

Throughout the project, I progressed from basic SQL queries to more advanced topics including filtering, aggregation, grouping, joins, subqueries, and window functions. This project strengthened my understanding of relational databases while demonstrating how SQL supports epidemiological research and public health data analysis.

## Basic SQL Queries

The first milestone introduced the core SQL commands used to retrieve information from a database.

I gained experience with:

* `SELECT`
* `FROM`
* `LIMIT`
* Selecting specific columns
* Querying entire tables

These commands form the foundation of nearly every SQL workflow.

## Filtering Data

Filtering allows analysts to focus on relevant subsets of information.

During this project, I learned how to use:

* `WHERE`
* Comparison operators
* Logical operators
* Pattern matching
* Multiple filtering conditions

Filtering is essential when analyzing large epidemiological datasets.

## Aggregating Data

Aggregation makes it possible to summarize large amounts of information.

I explored functions such as:

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`

These functions helped answer questions about COVID-19 cases, deaths, and testing trends.

---

## Grouping Data

Grouping allows SQL to summarize information by category.

During this stage, I learned how to:

* Use `GROUP BY`
* Calculate grouped statistics
* Compare countries
* Summarize epidemiological trends
* Analyze grouped datasets

Grouping is widely used in public health reporting and business analytics.

## Sorting Data

To organize query results, I explored SQL sorting techniques.

This included:

* `ORDER BY`
* Ascending order
* Descending order
* Multi-column sorting

Sorting improves readability and helps identify important trends within datasets.

## SQL Joins
